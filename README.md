# Ferrero Rocher Sales Analytics

An end-to-end business intelligence portfolio project analysing Ferrero Rocher sales performance using Python and Tableau.

## Project Objectives

This project aims to:

- Analyse sales and revenue performance
- Identify trends across products, customers, regions and channels
- Evaluate promotional effectiveness
- Explore customer purchasing behaviour
- Develop an interactive Tableau dashboard
- Translate data findings into actionable business recommendations

## Tools

- Python
- Pandas
- Jupyter Notebook
- Tableau
- GitHub

## Project Workflow

1. Understand the dataset
2. Assess data quality
3. Clean and transform the data
4. Perform exploratory data analysis
5. Define business KPIs
6. Prepare Tableau-ready data
7. Build the Tableau dashboard
8. Generate business insights and recommendations
9. Document the project
